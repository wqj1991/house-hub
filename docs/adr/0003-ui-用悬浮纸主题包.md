# 0003 UI 用「悬浮纸」主题包，外壳只一套

> 迁入自 `D:\repos\house\docs\adr\0003-ui-用悬浮纸主题包.md`（2026-11-13）。本仓库为真值；house 仓库的同名副本待其退役时删除。

应用的外壳与视觉全部来自 `docs/ui/` 的「悬浮纸」主题包（`theme.css` 五合一产物），页面只写主题包的语义类，不再写 Tailwind 原子类；外壳统一为 `sidebar / main / rail` 三栏，窄屏折叠成抽屉，删掉原来的 `TabBar` 与 `DesktopRail` 两套布局。

理由：同一份页面要同时长在桌面与安卓上，两套外壳意味着每个视觉问题修两遍；而且主题包自带令牌、断点与审计脚本（`tools/audit.js`、`resp.js`），能把「看起来对不对」换成可复跑的数字。

考虑过的选项：

- **继续 Tailwind + shadcn 自建**：样式散在 JSX 里，430px 上曾出现键值行被裁；也无法用主题的审计基线做回归。
- **双外壳**（移动底栏 + 桌面右栏）：平台判定靠 UA，桌面窗口拖到 700px 宽就会选错布局；抽屉与侧栏的焦点/Esc 行为要写两份。
- **只引 theme.css 不加自有样式**：主题包没有长文档排版规则，376 行的买房攻略会把表格撑出屏幕。

代价：主题包是外部生成物，升级要先跑 `node tools/build-css.mjs` 再同步 `src/styles/`；项目自有样式集中在 `src/styles/app.css` 一个文件，新增类必须写清为什么主题包没有。
